# Herlinda Portfolio — Pink V5

Portofolio Herlinda Rosalin Buarlele dari versi Pink V5 terakhir. Desain dan isi `index.html` dipertahankan dari berkas sumber yang ditemukan.

Foto dan sertifikat Nuri sudah tertanam di dalam HTML. Tidak diperlukan proses build. Font Google dimuat melalui internet, dengan font sistem sebagai cadangan.

## GitHub Pages

- Repository tujuan: `lilin4u.github.io` milik akun `lilin4u`.
- Entry point: `index.html` di root repository.
- Sumber Pages: branch `main`, folder `/ (root)`.
- Berkas `.nojekyll` disertakan untuk penyajian statis.
- URL tujuan setelah publikasi berhasil: `https://lilin4u.github.io/`.

URL tersebut harus diperiksa setelah deployment. Paket ini sendiri tidak membuktikan bahwa situs sudah diterbitkan.
